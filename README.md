# 📚 Library Management System

A simple command-line based **Library Management System** built with **Python**.  
This project allows users to manage books in a library — add, search, issue, and return books easily.

---

## 🚀 Features

| Feature | Description |
|--------|-------------|
| ➕ Add Book | Add a new book to the library |
| 📋 Show All Books | Display all books with their status and borrower info |
| 🔍 Search Book | Search for a specific book by name |
| 📤 Issue Book | Issue a book to a borrower |
| 📥 Return Book | Return a previously issued book |
| 🚪 Exit | Exit the program |

---

## 🖥️ How to Run

Make sure you have **Python 3** installed on your computer.

```bash
python library_management_system.py
```
